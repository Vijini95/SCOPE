# SCOPE

Code and supplementary material for *SCOPE: A Family of CDF-Based Wavelet Shrinkage Rules*, by Dixon Vimalajeewa, Vijini Lakmini, Malith Premarathna, Fabrizio Ruggeri, and Brani Vidakovic.

## Start with MATLAB

Open MATLAB in [matlab/](matlab/). The header of the self-contained driver specifies MATLAB R2018b or newer and no toolbox requirements. Start with the smoke run, then use the full design. The full run uses four Donoho–Johnstone signals, sample sizes 512, 1024, and 2048, root SNRs 3, 5, and 7, and 1,000 paired replications per condition.

    SCOPE_Exp123_FINAL('smoke','all')
    SCOPE_Exp123_FINAL('full','all',[512 1024 2048],[3 5 7],1000)

Use Exp1, Exp2, or Exp3 instead of all to run one study. Outputs and checkpoints go into SCOPE_Exp123_results next to the driver. The code exports comparator implementation notes for Experiment III. Before quoting a particular table, check its calibration convention and comparator status in the manuscript and supplement. The bundled historical CSVs may reflect different driver revisions. The separate scope7.m script plots exponential-power shrinkage profiles.

## Python notebooks

- [SCOPE_Exp123.ipynb](notebooks/SCOPE_Exp123.ipynb) translates the original three-experiment MATLAB driver.
- [SCOPE_Exp123_BNrounded.ipynb](notebooks/SCOPE_Exp123_BNrounded.ipynb) translates the rounded-noise-budget variant.

Both use a Python 3 kernel. Install NumPy, SciPy, pandas, Matplotlib, and JupyterLab. Inspect the configuration cell before running all cells. For figure text, disable LaTeX rendering if your machine has no TeX installation. These notebooks are archived translations. Exact agreement with the latest MATLAB driver has not been checked.

## Manuscript and supplement

- [Manuscript PDF](manuscript/SCOPE07.pdf) and [LaTeX source](manuscript/SCOPE07.tex).
- [Supplement02.tex](supplement/Supplement02.tex, SCOPE supplementary material.pdf) gives the penalized-likelihood and MAP interpretation, structural proofs, additional CDF constructions, null-risk calibration and SURE derivatives. It also gives the extended numerical tables for Experiments I–III and the comparator and reproducibility audit.

The supplement is included as the supplied LaTeX source. Its original references.bib and Figs/SCOPE_Mixture_Profiles.pdf were not available for this bundle. The main manuscript source similarly uses external bibliography and figure files. Use the supplied manuscript PDF to read the rendered paper.

## Earlier analyses and saved summaries

- [Rounded noise-budget MATLAB code](variants/rounded-bn/) includes the corrected bundle, the separate BN archive scripts, and the Section 5 comparison material. The comparison script expects full per-experiment result directories generated by the drivers, not only the aggregate CSVs below.
- [Earlier SURE experiments](variants/earlier-sure/) include the Python and MATLAB SURE prototype and the MATLAB Experiment II package with its helper functions.
- [R implementation](variants/r/) includes the all-in-one R driver and the annotated modular scripts with their launchers.
- [Earlier MATLAB bundle](variants/earlier-matlab/) includes the prior complete driver and its launchers for historical comparisons.
- [Saved result summaries](results/) includes aggregate AMSE and RMSE CSVs from the original and rounded-B_N runs. Full checkpoints and duplicate archive files are omitted.

The repository bundle was assembled from the available source and archived results. MATLAB, R, notebooks, and the supplement build have not been rerun for this release.
